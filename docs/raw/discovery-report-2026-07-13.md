## Deliberately not emitted (deletion test)

- **No induction of the PRD as a spec document.** Flagged as a human decision in the
  constitution's open questions rather than executed, since specs are outside
  discovery's output contract (instruction set section 2) even though RFC-003 section
  4 would otherwise support it.
- **No separate ADR for the Gate 3 LB-reachability mechanism** (`CiliumL2AnnouncementPolicy`
  vs a host route). This is a real, closed decision with a real alternative
  (`docs/planning/PRD.md` Section 6, line 124; Phase 0 step 4 in the plan), but it is
  tactical rather than architectural, thinly evidenced beyond "resolved empirically,"
  and unlikely to recur as a decision point for a future contributor. It is folded
  into `knowledge/context.md` implicitly via the Cilium/CNI stack description instead.
  Applying the deletion test: a standalone ADR here would cost a review glance without
  being consulted again, since the mechanism is now simply how the system works, not a
  live fork in the road.
- **No separate ADRs for the three Phase 3 "external input" decisions** (domain choice,
  Cloudflare Tunnel credentialing mode, Dex connector type) - recorded in
  `docs/planning/PLAN-ephemeral-gitops-idp-2026-07-05.md` "Decisions" item 5. These are
  user-supplied operational parameters (an existing Cloudflare zone, an existing tunnel
  object, a GitHub OAuth app), not decisions between architectural alternatives the
  project itself weighed - the "alternative" in each case was simply "ask the user,"
  which does not meet the ADR bar in RFC-003 section 4 or the instruction set's
  "discernible alternatives and consequences" test. The one real accepted-gap
  consequence of the tunnel-credentialing choice (ingress not Flux-reconciled) is
  captured in `knowledge/context.md`'s "Known accepted gaps" instead.
- **No induction of either zoom-out report.** Zoom-out reports are not one of
  RFC-003's minimal artifact types, and their durable content is already carried
  forward into ADR-0001 and the constitution with full citation back to the originals.
- **No context-document split** (into separate `systemPatterns`/`techContext`/
  `productContext` files). Per the instruction set's alternatives-considered section,
  a single combined file is correct at this stage; there is no evidence any section
  would grow disproportionately soon.

## Open questions for the human, ordered by how much their answer would change the drafts

1. **Should `docs/planning/PRD.md` be inducted as `knowledge/specs/spec-ephemeral-gitops-idp.md`?**
   This is the highest-leverage open question: the PRD is the single densest source
   behind the constitution, and inducting it would let the constitution's citations
   point at a governed document instead of an ungoverned one, and would let the human
   formally close it out (`archived`) once Phase 4/5 finish, per RFC-003 section 4's
   PRD lifecycle. No conflict is being hidden here - this is a scope question, not a
   factual dispute.
2. **Is the constitution's synthesized "definition of done" an accurate reflection of
   intent?** No single document states it in one place (see the constitution's own
   flagged question); it was built by combining the engineering gates (Section 4) and
   success metrics (Section 7) of the PRD, which agree in shape but were never
   co-located. Confirm before promoting past `draft`.
3. **Should ADR-0004's rationale for a persistent (vs per-cycle) deploy key be
   filled in from the human's memory?** This is the one explicit low-confidence
   inference in the entire run; the plan records the choice but not why, and no other
   document supplies the missing reasoning.
4. **No genuine conflicting evidence was found across the seven planning documents
   read.** Where two documents disagreed (the two ZORs' verdicts; the PRD's own
   sections 8-10 "corrections applied"), the disagreement was already explicitly
   resolved and dated by the later document, and the earlier one self-marked as
   superseded - this is documented history, not an unresolved conflict, so nothing was
   recorded as an open question on this account. Flagging this explicitly per the
   evidence-discipline requirement to state when no conflict was found rather than
   silently implying a search was skipped.
